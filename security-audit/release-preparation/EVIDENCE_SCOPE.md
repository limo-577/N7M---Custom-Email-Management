# 正式提交的证据范围

本次整理保留实际实现、188 项测试、完整原始审计及必要的历史调查、依赖来源、五个补丁的固定提交/差异和失败结论、构建与安装包静态验证结果。没有重新执行这五个补丁实验。

`curation.json` 记录保留文件的原始 SHA-256。历史报告属于对应的历史测试提交，不代表本次正式提交已获风险批准；其中记载的快照 SHA、测试授权 ID 和产物摘要不能用于本次发布。

旧调查的全量原件、before 副本、重复日志、旧源码下载副本、测试签名 envelope、公钥、消费/撤销账本副本、生成签名的本地验证脚本等，均保存在本机已忽略的 `.risk-build/release-preparation-archive-20261118/`，不纳入提交。历史报告中对这些详细文件的引用应按本说明理解。未删除原始证据，也未改写 raw audit。

`test-results/` 内测试仓库、临时批准方目录，以及 `release/` 中验证安装包本来就在忽略范围内。它们不属于正式源码或生产授权。此提交不包含私钥、公钥文件、有效/已撤销的签名 envelope、安装包或账户/密库数据；公钥的实际配置由批准方另行操作。

另将 36 个原已忽略的 2026-11-17 派生文本日志保存到同一归档的 `previous-ignored/`，避免它们留在源码目录而触发严格的未审查文件拒绝。仅归档已核对为未跟踪且被忽略的调查日志，未删除或读取用户账户/密库配置。

新一轮正式提交候选的审计、测试及构建结果位于本目录。具体被测试的候选 tree、运行时源码摘要和最终提交的关系在 REPORT.md / verification.json 中说明；候选构建不等于正式发布批准。
