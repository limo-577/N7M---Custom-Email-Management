# N7M - Custom Email Management

Windows 桌面邮箱与浏览器账号管理工具，当前版本 **1.3.0**。

## 账号管理

- 所有账号集中在一张表格中管理，取消左侧栏，扩大字号并收紧留白。
- 顶部提供账号分组、冷却设置、批量启动页设定、导入资料、添加账号、打开快捷栏。清空全部账号采用文字按钮，位于修改软件密码左侧，需单独确认，不再放在搜索栏旁。
- 顶部 Profile 帮助入口可复制 `chrome://version`、`edge://version`、`brave://version`。在对应浏览器地址栏打开后，查看 Profile Path，将路径最后一级目录（如 Default、Profile 43）填入账号 Profile。
- 浏览器类型支持 A→Z / Z→A 排序及恢复导入顺序；同类浏览器相邻，同类账号保留原顺序，未设浏览器的账号始终排在末尾。
- 点击账号分组直接展开下拉菜单，可筛选、添加和删除分组；勾选账号后可直接移入或移出分组。空分组也会保存在加密资料库中。删除分组只移除归属，保留账号、密码和 TOTP。
- 一行显示全局统计：全部账号、可启动、冷却中、待完善。搜索或分组筛选不会改变全局统计口径。
- 表格列：软件编号、邮箱资料 / 密码 / TOTP / 分组、浏览器 / Profile、备注、状态 / 冷却时间、操作。
- 每行保留一个编辑图标和“启动”按钮。未设置浏览器时提示待完善，不自动分配浏览器或编号。
- 启动网页可以留空，留空时直接启动浏览器；填写后打开自定义网页。支持 Chrome、Edge、Brave 和系统默认浏览器。
- 编号可留空，密码与 TOTP 也是可选项，不影响已配置浏览器的账号启动。冷却中的账号可以手动恢复可用。
- 按邮箱、编号、浏览器、备注、分组或标签搜索；批量编辑、启动、恢复可用、导出和删除。
- 全局默认冷却时间与单账号覆盖，支持小数；到期后自动视为可用。

Profile 查看方法参考：[Chrome / Chromium 官方说明](https://chromium.googlesource.com/chromium/src/+/HEAD/docs/user_data_dir.md)、[Microsoft Edge 官方说明](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/userdatadir)、[Brave 官方项目说明](https://github.com/brave/brave-browser/issues/16034)。

## 密码、TOTP 与软件锁

首次启动需要设置至少 8 位的软件密码，随后每次启动均需解锁。软件密码可在顶部修改；Windows 锁屏或系统休眠时自动锁定，也可手动锁定。

整个资料库使用 AES-256-GCM 加密，密钥由软件密码通过 scrypt 派生，每次写入使用随机 nonce。加密密钥只在解锁期间持有，锁定后清除密钥并重新加载界面；数据读取、修改、复制、导出和启动操作都会检查锁定状态。备份同样加密，修改软件密码时同步更新备份。

编辑账号时填写登录密码和 TOTP 密钥。密码保留原样，包括前后空格。列表只显示“密码”和“TOTP”两个文字入口，不显示密码、密钥或验证码；点击密码复制登录密码，点击 TOTP 复制当前 6 位验证码。复制的凭据在 30 秒后或软件锁定时清理；若已复制其他内容，不会覆盖你的新剪贴板内容。

TOTP 支持 Base32 密钥和 `otpauth://totp` 链接，使用标准 SHA1 / 6 位 / 30 秒算法。电脑时间需要准确。软件密码无法找回，请妥善保管；丢失软件密码就无法解密资料。

## 数据与升级

为兼容安装版和免安装版，数据目录保留为 `%APPDATA%/email-manager/`，安装 appId 保持不变。显示名称统一为 **N7M - Custom Email Management**。

- 新资料文件：`email-vault.json`；备份：`email-vault.json.bak`。
- 首次设置软件密码时读取旧版 `email-data.json`，在完成加密写入及验证后移除旧版明文文件、临时文件和备份。
- 旧文件损坏时保留原文件，不覆盖、不清空账号。加密文件损坏时可保留原件后使用加密备份恢复。
- 清理旧版文件前比对加密保存的迁移指纹；旧版本后来新增或修改的资料文件会被保留并提示，不会静默删除或自动覆盖新版资料。
- 新版启用后请使用 1.3.0 或更新版本管理同一份资料。1.2 版支持加密但不保留新增的独立分组目录，1.1 及更早版本不支持加密资料库。
- 账号数据不随免安装 EXE 一起移动。换电脑时，在关闭软件后复制加密资料文件，再用原软件密码解锁；浏览器 Profile 仍依赖目标电脑已配置的浏览器。

## 导入与导出

支持 Excel `.xlsx`、CSV、TSV、粘贴表格，含多工作表选择、导入预览、缺项提示、重复跳过。旧 `.xls` 请另存为 `.xlsx`。

Excel 在独立工作线程中读取，可随时取消；锁定软件、关闭窗口或读取超过 15 秒时终止解析，不会保存部分账号。文件最大 20 MiB，最多 30 个工作表，每表最多 50,000 行、100 列，总计最多 250,000 个单元格、400 万字符，单元格最多 32,767 字符。ZIP 最多 512 项，单项实际解压最多 16 MiB、合计最多 64 MiB；超过限制会提示拆分文件。线程配置了 192 MiB 的 JavaScript 老生代堆限制，该值不是整个应用或系统内存的硬上限。CSV、TSV 和粘贴表格的行为保持不变。

推荐第一行表头，列顺序可以调整：

```text
邮箱链接,浏览器,Profile,编号,启动网页,备注,分组,标签,冷却小时,密码,TOTP密钥
user@example.com,Chrome,Profile 43,001,,工作用途,工作,"常用,项目A",24,,
```

兼容旧版无表头三列 `邮箱 / 浏览器 / 编号` 和四列 `邮箱 / 浏览器 / Profile / 编号`，支持 Tab 或逗号分隔、连续空列、带引号的逗号和多行备注。Excel 编号使用文本或 `000` 数字格式保留前导零。

**CSV 导出不包含账号密码或 TOTP 密钥**，仅导出普通账号资料。完整备份请保留加密资料库文件。

## 开发、验证与打包

需要 Node.js 22+。密码锁和加密存储在 Electron 主进程中运行，浏览器预览不提供明文存储后备方式。

```powershell
npm install
npm run dev
npm test
npm run test:ui
npm run dist:all
```

输出 Windows x64 三种分发形式：

- `release/N7M - Custom Email Management-1.3.0-Setup.exe`：安装版。
- `release/N7M - Custom Email Management-1.3.0-Portable.exe`：单文件免安装版。双击启动会先解压到系统临时目录，退出后清理，启动时需稍等片刻。
- `release/N7M - Custom Email Management-1.3.0-NoInstall.zip`：解压免安装版。完整解压后运行同目录的主 EXE，保留 DLL、resources、locales 等配套文件，日常启动更快。

开发版桌面流程测试使用独立目录与测试账号；指定 `N7M_PACKAGED_TEST=1` 可对 `release/win-unpacked` 的实际打包程序运行同一套验证。
